HOW TO READ THE RESULTS

Interpretation

01

Top reported scores

The Amazon educational proxy has the highest reported accuracy and churn F1 in this table. That describes its generic proxy holdout only. Netflix is the next-highest on these reported metrics, with its own provenance and target limitations.

02

Precision and recall

Churn precision indicates how many flagged customers were labeled churners. Churn recall indicates how many labeled churners were detected. Improving one can reduce the other; F1 summarizes their balance.

03

Accuracy is not enough

Accuracy combines correct predictions across both classes and can hide weak detection of a less common class. Churn precision, recall, F1, class balance, and the cost of errors also matter.

04

Different tasks, different evidence

These models were evaluated on different datasets and holdouts, with different label definitions and provenance. The scores do not establish that one algorithm or company model is generally superior.

METHODOLOGY & LIMITATIONS

Important dataset context

Read before comparing
JIO + AIRTEL

Project audits identify overlapping customer records and status labels between these datasets. They are not independent company evidence.

NETFLIX

The report flags unverified dataset provenance, churn definition, and timing of behavior features. Its unusually high reported score warrants caution and is not external validation.

AMAZON

The model is an educational proxy trained on generic customer churn data. It is not a genuine Amazon Prime churn model, and its metrics are not Prime performance.

PROXY TEST FILE

The generic supplied test file has 62,995 overlapping training IDs, including 32,778 shared IDs with conflicting labels. It was not used as an independent evaluation set; reported proxy metrics use an internal stratified holdout from the generic training file.

CROSS-DATASET COMPARISON

Metric values come from different datasets and evaluation setups. Variations in source, target, class distribution, and feature timing limit direct ranking and generalization claims.

All metric values are read from the existing comparison reports. The comparison page does not retrain models or recalculate scores on another evaluation set.
